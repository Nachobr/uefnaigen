# Compact Solo Tycoon

> A compact coin tycoon with two purchases, one gate, save, and short rebirth loop.

**Genre:** tycoon
**Session Length:** 12 minutes
**Core Loop:** collect coins → buy upgrades → unlock a zone → save progress → rebirth

## Zones (6)

- **Starter Pad** — Compact spawn and first coin collector.
- **Coin Loop** — Short collection loop for smoke testing income.
- **Upgrade Kiosk** — Two visible purchases and rebirth button.
- **Bonus Alcove** — Single locked zone opened by the second purchase.
- **Upgrade Lane** — Linear purchase lane for visible progression checks.
- **Automation Yard** — Worker and passive income setup area.
