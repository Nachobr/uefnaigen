# Design Summary — Compact Solo Tycoon

## Fantasy
A compact coin tycoon with two purchases, one gate, save, and short rebirth loop.

## Theme
small clean tycoon pad designed for fast UEFN import smoke testing

## Core Loop
1. collect coins
2. buy upgrades
3. unlock a zone
4. save progress
5. rebirth

## Session Pacing
- **Early Game:** Spawn in Starter Pad, learn income, and buy the first upgrade within 45–90 seconds.
- **Mid Game:** Route through Upgrade Kiosk to add automation and unlock the gated area.
- **Late Game:** Use Bonus Alcove for prestige/rebirth setup and creator handoff checks.

## Progression Beats
- Earn first coins from Coin Loop.
- Buy Coin Upgrade near the one-minute mark.
- Unlock Auto Collector and open Bonus Alcove.
- Reach Quick Rebirth by the target session end.
