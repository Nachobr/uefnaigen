# Design Summary — Lumber Mill Starter

## Fantasy
Build a colorful lumber business from chopping grove to automated sawmill.

## Theme
bright forest mill with sawdust paths and cozy work yards

## Core Loop
1. chop trees
2. sell logs
3. buy upgrades
4. unlock sawmills
5. prestige

## Session Pacing
- **Early Game:** Spawn in Starter Grove, learn income, and buy the first upgrade within 45–90 seconds.
- **Mid Game:** Route through Sawmill Shop to add automation and unlock the gated area.
- **Late Game:** Use Prestige Ridge for prestige/rebirth setup and creator handoff checks.

## Progression Beats
- Earn first wood from Log Yard.
- Buy Sharper Axe near the one-minute mark.
- Unlock Hire Mill Workers and open Prestige Ridge.
- Reach Prestige Mill by the target session end.
