# Lumber Mill Starter

> Build a colorful lumber business from chopping grove to automated sawmill.

**Genre:** tycoon
**Session Length:** 20 minutes
**Core Loop:** chop trees → sell logs → buy upgrades → unlock sawmills → prestige

## Zones (7)

- **Starter Grove** — Safe spawn with first trees and tutorial signs.
- **Log Yard** — Dense trees feeding the first sell loop.
- **Sawmill Shop** — Axe, sawmill, and worker automation purchases.
- **Prestige Ridge** — Late-game prestige gate with multiplier signage.
- **Upgrade Lane** — Linear purchase lane for visible progression checks.
- **Automation Yard** — Worker and passive income setup area.
- **Rebirth Platform** — Prestige and rebirth handoff test platform.
