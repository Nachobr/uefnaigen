# Design Summary — Mining Empire Starter

## Fantasy
Grow a mining company from hand-mined ore to automated drill operations.

## Theme
layered mine with glowing ore seams, furnaces, drills, and gem caves

## Core Loop
1. mine ore
2. smelt bars
3. upgrade tools
4. unlock caves
5. prestige for gems

## Session Pacing
- **Early Game:** Spawn in Surface Claim, learn income, and buy the first upgrade within 45–90 seconds.
- **Mid Game:** Route through Furnace Row to add automation and unlock the gated area.
- **Late Game:** Use Deep Gem Cave for prestige/rebirth setup and creator handoff checks.

## Progression Beats
- Earn first ore from Iron Vein.
- Buy Pickaxe Upgrade near the one-minute mark.
- Unlock Hire Miners and open Deep Gem Cave.
- Reach Gem Prestige by the target session end.
