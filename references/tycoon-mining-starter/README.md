# Mining Empire Starter

> Grow a mining company from hand-mined ore to automated drill operations.

**Genre:** tycoon
**Session Length:** 20 minutes
**Core Loop:** mine ore → smelt bars → upgrade tools → unlock caves → prestige for gems

## Zones (7)

- **Surface Claim** — Spawn claim with first ore rocks and tutorial board.
- **Iron Vein** — Early ore nodes and minecart sell route.
- **Furnace Row** — Smelter, pickaxe, drill, and miner purchases.
- **Deep Gem Cave** — Prestige cave gated by late mining upgrades.
- **Upgrade Lane** — Linear purchase lane for visible progression checks.
- **Automation Yard** — Worker and passive income setup area.
- **Rebirth Platform** — Prestige and rebirth handoff test platform.
